# COORD_CALLOUT.lsp

AutoLISP-скрипт для AutoCAD, автоматизирующий простановку координатных выносок и линейных размеров по вершинам полилинии — стандартная задача при оформлении геодезических / топографических чертежей.

Скрипт проставляет координаты X/Y по каждой вершине выбранной полилинии (или сразу нескольких), номера вершин, размеры по каждому сегменту (с учётом рядом расположенных М-линий), а также формирует и экспортирует итоговую таблицу координат — без ручного черчения выносок и без ручного набора текста.

## Возможности

- **Координаты по вершинам полилинии** — на выбор один из двух способов вывода:
  - **Мультивыноска (MLEADER)** со строками `X= ...` / `Y= ...`;
  - **Атрибутивный блок «XY»**, вставляемый точкой вставки прямо в вершину — без линии-выноски.
- **Выбор сразу нескольких полилиний за один запуск** — координаты, номера и размеры проставляются по каждой из них, со сквозной нумерацией вершин между ними.
- **Одна подпись на одну точку.** Если несколько полилиний имеют совпадающие вершины, в одну геометрическую точку ставится только одна координатная подпись и один номер (дубликаты пропускаются).
- **Параллельные размеры** по каждому сегменту полилинии, смещённые от линии на 0.5:
  - если сегмент достаточно длинный — значение показывается прямо на линии размера;
  - если сегмент короткий и цифры не помещаются — значение автоматически выносится отдельной мультивыноской в сторону.
- **Учёт М-линий рядом с полилинией.** Если вдоль сегмента проходит М-линия:
  - при разнице длин ≤ 0.15 размер полилинии **не** ставится (остаётся только подпись М-линии `L=` / `L-`);
  - при разнице длин > 0.15 ставятся **оба** размера.
  - Префикс (`L=` или `L-`) выбирается при запуске команды.
- **Сквозная нумерация вершин** между несколькими полилиниями в рамках одного сеанса — с выбором **Авто** (продолжить / начать заново) или **Вручную** (указать стартовый номер).
- **Автоматическое обновление координат при перемещении и копировании блока.** Если координата вставлена как атрибутивный блок, его впоследствии переместили (MOVE, растяжение, ручки) или скопировали (COPY) — значения X/Y в атрибутах пересчитываются автоматически.
- **Экспорт таблицы координат** по завершении построения — в CSV (для Excel) и/или RTF (для Word).
- **Самодостаточный файл.** Чертёж-шаблон с нужными стилями оформления встроен в сам `.lsp`-файл (в виде base64) и автоматически распаковывается при первой загрузке.
- **Автоматический импорт оформления** из встроенного шаблона: стиль мультивыноски «Координаты», текстовый стиль «Д-431», размерный стиль «ISO-500 пустой COORD», блок «XY». Если импорт не удался — скрипт продолжает работу на базе стиля Standard, назначая оформление вручную.

## Требования

- AutoCAD (или платформа на его движке, поддерживающая AutoLISP + Visual LISP / ActiveX).
- Права на запись во временную папку пользователя (`%TEMP%`) — туда распаковывается встроенный шаблон стилей при первой загрузке.
- Папка со скриптом должна входить в список «Доверенные расположения» AutoCAD (**ОПЦИИ → Файлы → Доверенные расположения**) — иначе загрузка через APPLOAD завершится ошибкой без подробностей.

## Установка

1. Скачайте файл `COORD_CALLOUT.lsp`.
2. Загрузите его в AutoCAD одним из способов:
   - команда **APPLOAD** (**ЗАГПРИЛ**) → выбрать файл → «Загрузить»;
   - перетащить файл в окно AutoCAD;
   - добавить в автозагрузку через **Диспетчер приложений** (APPLOAD → «Стартовый набор» / Startup Suite), если скрипт нужен постоянно.
3. При успешной загрузке в командной строке появится:

```
+---------------------------------------------------+
|  vertex_leaders.lsp успешно загружен.             |
|  Доступные команды:                               |
|   VERTEXLEADERS  — координаты + размеры + экспорт |
|   CHECKSTYLE     — проверить/импортировать стили  |
|   RESETVERTEXNUM — сбросить счётчик нумерации     |
+---------------------------------------------------+
```

> При самой первой загрузке скрипт распаковывает встроенный чертёж-шаблон во временную папку (`%TEMP%\template.dwg`) — это происходит один раз и подтверждается сообщением «Распаковываю встроенный шаблон стилей... Готово.».

## Команды

### `VERTEXLEADERS`

Основная команда. Последовательность работы:

1. Запустите команду и выберите одну или несколько полилиний (`LWPOLYLINE`, `POLYLINE` или `3DPOLYLINE`) — завершите выбор клавишей ENTER.
2. Ответьте на вопросы (значение по умолчанию в `<>`, достаточно нажать ENTER):

   - **Проставлять номера вершин?** `[Да/Нет] <Да>`
   - **Проставлять размеры сторон?** `[Да/Нет] <Да>`
   - если размеры включены → **Префикс длины М-линий?** `[L=/L-] <L=>`
   - **Способ вывода координат?** `[Мультивыноска/Блок] <Мультивыноска>`
   - если номера включены → **Нумерация вершин?** `[Авто/Вручную] <Авто>`
     - **Авто** — продолжить с прошлого номера или начать с 1 (с вопросом «Продолжить/Заново», если в сеансе уже была обработка);
     - **Вручную** — ввести стартовый номер с клавиатуры.

3. Скрипт автоматически проставит по каждой выбранной полилинии:
   - координатные подписи по каждой **уникальной** вершине;
   - номера вершин (если включено);
   - параллельные размеры по сегментам — с учётом М-линий (см. ниже).
4. По завершении будет предложено экспортировать итоговую таблицу координат в CSV и/или RTF.

**Пример диалога:**

```
Команда: VERTEXLEADERS
=== Простановка координатных выносок и размеров по полилинии ===
  Выберите нужные полилинии (можно несколько).
  Когда все нужные объекты выбраны — нажмите ENTER, чтобы завершить выбор.
Выберите объекты: найдено: 1
Выберите объекты: найдено: 1, всего: 2
Выберите объекты:
  Выбрано полилиний: 2
Проставлять номера вершин? [Да/Нет] <Да>: Д
Проставлять размеры сторон? [Да/Нет] <Да>: Д
Префикс длины М-линий? [L=/L-] <L=>: L=
Способ вывода координат? [Мультивыноска/Блок] <Мультивыноска>: М
Нумерация вершин? [Авто/Вручную] <Авто>: А
  Нумерация вершин начнётся с №1.
```

### `CHECKSTYLE`

Служебная команда — проверяет наличие и при необходимости повторно импортирует текстовый стиль «Д-431» и стиль мультивыноски «Координаты» из встроенного шаблона. Удобна для быстрой проверки оформления без запуска полного цикла построения.

### `RESETVERTEXNUM`

Сбрасывает сквозной счётчик нумерации вершин, накопленные данные для экспорта и карту занятых мест под подписи. Используйте, если нужно начать нумерацию заново «с чистого листа» в рамках текущего сеанса, не перезапуская AutoCAD.

### `REFRESHCOORDBLOCKS`

Служебная команда, связанная с автообновлением координат в атрибутивных блоках (см. раздел ниже). Пере-навешивает системные реакторы на все блоки «XY» в текущем чертеже. **Обязательно выполняйте её один раз после каждого открытия/переоткрытия файла**, содержащего ранее расставленные координатные блоки — реакторы не сохраняются в самом DWG между сеансами AutoCAD.

## Размеры и М-линии

Если вдоль сегмента полилинии проходит М-линия (например, дорога или коммуникация):

| Условие | Поведение |
|---|---|
| М-линия рядом **и** разница длин ≤ 0.15 | Размер полилинии **не** ставится. Ставится только подпись М-линии (`L=` / `L-`). |
| М-линия рядом **и** разница длин > 0.15 | Ставятся **оба** размера: и полилинии, и М-линии. |
| М-линии рядом нет | Размер полилинии ставится как обычно. |

Дополнительно:

- подпись М-линии строится как `<префикс><длина>`, например `L=24.15` или `L-14.00`;
- если несколько выбранных полилиний оказались рядом с одной и той же М-линией, подпись для неё ставится только один раз за весь запуск;
- на коротких сегментах значение выносится мультивыноской.

## Автообновление координат при перемещении и копировании блока

При использовании способа вывода **«Блок»** скрипт навешивает на каждый вставленный блок системный реактор AutoCAD. Как только блок перемещают (перетаскиванием, командой MOVE, растяжением) — значения атрибутов X/Y пересчитываются автоматически сразу после завершения команды редактирования.

Это работает и для **копий** блока: после копирования (COPY) новый экземпляр автоматически обнаруживается, на него навешивается реактор, а атрибуты X/Y пересчитываются по фактическому положению копии.

**Ограничение:** реакторы существуют только в оперативной памяти текущего сеанса и не сохраняются в DWG. При каждом новом открытии чертежа с уже расставленными блоками нужно один раз выполнить `REFRESHCOORDBLOCKS`.

## Настройка

Ключевые параметры оформления заданы в начале тела команды `VERTEXLEADERS` и могут быть изменены под конкретный проект:

| Параметр | Назначение | Значение по умолчанию |
|---|---|---|
| `mleader-style-name` | Имя стиля мультивыноски | `Координаты` |
| `text-style-name` | Имя текстового стиля | `Д-431` |
| `dim-style-name` | Имя размерного стиля | `ISO-500 пустой COORD` |
| `coord-block-name` | Имя блока для режима «Блок» | `XY` |
| `block-scale` | Масштаб вставки блока (высота текста атрибутов не зависит от него) | `1.0` |
| `txt-height` | Высота текста координат/номеров | `1.0` |
| `dim-offset` | Смещение линии размера полилинии от самой полилинии | `0.5` |
| `dim-text-gap` | Отступ текста от линии размера | `0.5` |
| `parallel-search-dist` | Радиус поиска соседних выбранных полилиний (для выбора стороны размера) | `10.0` |

Параметры поиска М-линий и порог разницы длин (0.15) заданы внутри функций `vl:mline-near-segment-p` и `vl:dim-mlines-near-polyline`.

## Известные ограничения

- Реакторы автообновления координат сбрасываются при закрытии чертежа/AutoCAD — требуется `REFRESHCOORDBLOCKS` после каждого открытия файла.
- Импорт стилей из шаблона выполняется через временную вставку шаблонного DWG как блока с последующим удалением экземпляра; определение блока-шаблона остаётся в таблице блоков чертежа — это ожидаемое и безвредное поведение.
- Определение «М-линия рядом с сегментом» опирается на расстояние от середины сегмента и параллельность направлений. В редких случаях сложной геометрии (острые углы, М-линии вдоль соседнего сегмента) проверка может сработать не так, как ожидалось — стоит визуально проверить результат.
